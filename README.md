# Break vap and cbd

Je te fournis en pièce jointe le cahier des charges complet du projet "Break and Vap",

un site e-commerce pour une boutique française spécialisée dans le CBD et le vapotage

(e-liquides et accessoires uniquement, aucun appareil électronique).

Lis attentivement l'intégralité du document avant de commencer. Il contient :

- le modèle de données à respecter (section 6)

- les exigences de sécurité obligatoires (section 4)

- les fonctionnalités attendues côté client et côté espace admin (sections 7 et 8)

- les contraintes réglementaires françaises à respecter dès la conception (section 3)

Ne développe pas tout le site en une seule fois. Construis-le étape par étape en

suivant strictement l'ordre des 7 prompts détaillés dans la section 11 du document :

1. Fondations, modèle de données et sécurité de base

2. Vérification d'âge

3. Catalogue et fiches produits

4. Panier et tunnel de commande

5. Compte client

6. Espace admin gérant (sécurisé et intuitif)

7. Pages de contenu, légal et finitions

Commence uniquement par le Prompt 1 (fondations, modèle de données, sécurité de base).

Une fois que j'aurai validé ce premier bloc, je te donnerai le signal pour passer au

suivant. N'anticipe pas les blocs suivants avant validation.
